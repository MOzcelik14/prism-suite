Engineering Standards

Built for Production Reliability

Engineered to eliminate common points of failure in media production pipelines: broken updates, vendor lock-in, background telemetry overhead, and runtime dependency conflicts.

Atomic Upgrades & Rollbacks

Releases deploy into dedicated version directories (`versions/<version>`). The active release is switched atomically via filesystem symlinks on Linux and directory junctions on Windows. Revert to previous versions instantly in 1 click without data corruption.

Cryptographic Security

Binary distributions are authenticated with detached Ed25519 Minisign signatures and SHA-256 integrity verification. The archive engine sanitizes all paths to prevent traversal exploits (`../`) and unauthorized filesystem writes.

100% Local Sovereignty

Zero cloud requirement, zero tracking, and zero compulsory online accounts. Your creative work remains strictly on your local disk. The launcher operates reliably in fully air-gapped production studios.

Process Decoupling

Creative tools execute in decoupled process groups (`setsid` on Linux, independent creation flags on Windows). You can close or update the suite launcher without terminating or interrupting ongoing audio/video rendering.

Embedded Typography

The GUI embeds the DejaVu Sans typography engine directly within the binary. Full coverage for European, Turkish (`ç, ğ, ı, İ, ö, ş, ü`), and mathematical symbols renders crisply with zero system font dependencies.

Shared Preferences Sync

Automated configuration synchronization protocol (`shared.ron`) propagates active language selections (English and Turkish) and update channel preferences across all installed applications.

Install & Deploy

Production Packages (v0.2.0)

Official binary distributions for Linux and Windows. Choose the standard package format for your operating system or deploy the standalone portable packages.

Native Debian / Ubuntu Package

Installs binaries into `/usr/bin/prism`, system icons, and FreeDesktop menu entry.

Download .deb (6.1 MB)
Terminal Installation 
sudo dpkg -i prism_0.2.0_amd64.deb
sudo apt-get install -f

Native RPM Package

For Fedora, CentOS, Rocky Linux, and RHEL. Installs native desktop entries and dependencies.

Download .rpm (6.1 MB)
Terminal Installation 
sudo dnf install ./prism-0.2.0-1.x86_64.rpm

Standalone Portable AppImage

Single executable bundle compatible across all standard modern Linux distributions.

Download .AppImage (7.3 MB)
Execution 
chmod +x prism-0.2.0-x86_64.AppImage
./prism-0.2.0-x86_64.AppImage

Windows 10 / 11 Portable Archive

Standalone archive with `prism.exe`. Automatically manages junctions in `%LOCALAPPDATA%`.

Download .zip (Windows 64-bit)
PowerShell Quick Run 
Expand-Archive -Path .\prism-0.2.0-windows-x86_64.zip -DestinationPath C:\prism-suite
C:\prism-suite\prism.exe
Integrity & Trust

Cryptographic Verification Guide

Every official release archive published by the project is paired with a SHA-256 manifest and signed via Minisign (Ed25519).

SHA-256 Checksum & Signature Verification 
# 1. Download artifact, manifest, and detached signature
curl -LO https://github.com/MOzcelik14/prism-suite/releases/download/v0.2.0/SHA256SUMS.txt
curl -LO https://github.com/MOzcelik14/prism-suite/releases/download/v0.2.0/SHA256SUMS.txt.minisig

# 2. Verify SHA-256 hash match
sha256sum -c SHA256SUMS.txt --ignore-missing

# 3. Verify publisher Minisign signature (if minisign installed)
minisign -Vm SHA256SUMS.txt -P RWQkX1dC2Kz9...pubkey
